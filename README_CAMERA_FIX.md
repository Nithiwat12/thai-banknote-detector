# กล้อง: ตรวจทันทีและตัดกรอบครอบฉาก
แก้กรณีกรอบ 20 บาท confidence 0.79 ครอบเกือบเต็มภาพตามภาพที่ผู้ใช้ส่ง
ตัดกรอบพื้นที่ตั้งแต่ 85% ของภาพ หรือกว้าง >=95% และสูง >=90% ของภาพ
ตรวจ นับ และส่งข้อความเสียงจากเฟรมแรกที่ผ่านเกณฑ์ ไม่รอ 4 เฟรมหรือเวลา 0.25 วินาที
คงเกณฑ์ความมั่นใจกล้องขั้นต่ำ 0.60 และตัวกรองกรอบซ้ำ/คลาสขัดแย้ง
ผลนี้ป้องกันกรอบครอบฉาก ไม่ได้เปลี่ยนโมเดลให้ตรวจแบงก์ 50 ได้ถูกต้องโดยอัตโนมัติ
ธนบัตรจริงที่ถือใกล้จนเต็มภาพอาจถูกตัดด้วย ให้ถือห่างให้เห็นขอบและพื้นหลังรอบแบงก์
ไม่ใช้ภาพตัวอย่างนี้เป็น negative เพราะมีธนบัตรจริงอยู่ ต้อง label แบงก์ 50 ให้ถูกต้องหากนำไปเทรน
ทดสอบกรอบจำลองและผลส่งกลับ ไม่ได้ทดสอบกล้องจริงหรือ accuracy ใหม่
